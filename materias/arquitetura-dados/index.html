Destaques Cesgranrio — Arquitetura de Dados

  • SQL com cenário real — a banca mostra um schema e pede resultado de query com JOIN, GROUP BY e HAVING
  • Diferença entre DDL e DML — saber que TRUNCATE é DDL e não DML
  • ACID — saber definir cada propriedade e identificar qual está sendo violada num cenário
  • Normalização — 1FN, 2FN, 3FN, BCNF: saber identificar qual forma está violando
  • NoSQL — saber qual tipo (documento, chave-valor, grafos, colunar) se aplica a qual cenário
  • Modelagem dimensional — diferença entre fato e dimensão, estrela vs floco de neve
  • ETL vs ELT — tendência recente de perguntar sobre ELT em contexto de Data Lake
