UX — User Experience

💡 UX vs UI
UX (User Experience): toda a experiência do usuário com o produto — pesquisa, arquitetura de informação, fluxos, emoções.
UI (User Interface): a interface visual — cores, tipografia, botões, ícones. UI é uma parte da UX.

Usabilidade — ISO 9241

Usabilidade é a medida na qual um produto pode ser usado por usuários específicos para alcançar objetivos específicos com eficácia, eficiência e satisfação em um contexto de uso específico.

✅
Eficácia
O usuário consegue completar a tarefa? (Resultado correto)
⚡
Eficiência
Com que custo (tempo, cliques, esforço) o usuário completa a tarefa?
😊
Satisfação
O usuário ficou satisfeito com a experiência? (Subjetivo)

Acessibilidade

Acessibilidade é o design de produtos, dispositivos, serviços e ambientes para pessoas com deficiência. Na web, seguida pelas WCAG (Web Content Accessibility Guidelines) do W3C.

Princípio WCAGDescriçãoExemplo
PerceptívelInformação apresentável de diferentes formasAlt text em imagens, legendas em vídeos
OperávelComponentes navegáveis por tecladoTab order, skip navigation links
CompreensívelInformação e UI compreensíveisLinguagem simples, mensagens de erro claras
RobustoCompatível com tecnologias assistivasHTML semântico, leitores de tela

Personas

Persona é um arquétipo de usuário baseado em pesquisa qualitativa e quantitativa real — não é um personagem fictício inventado. Representa um grupo de usuários com comportamentos, objetivos e motivações similares.

⚠️ Pegadinha
Persona ≠ usuário real específico. É uma representação composta baseada em dados reais de pesquisa com múltiplos usuários. A banca pode apresentar persona como "personagem completamente fictício" — isso está ERRADO.

Design Thinking

Design Thinking é uma abordagem centrada no ser humano para resolução de problemas complexos e inovação. Popularizado pela IDEO e pela Stanford d.school.

As 5 Etapas (Modelo Stanford d.school)

1

Empatia (Empathize)

Entender profundamente os usuários — seus desejos, necessidades, comportamentos e contexto. Técnicas: entrevistas, observação, imersão, mapa de empatia.

2

Definição (Define)

Sintetizar os aprendizados da empatia para definir o problema real. Resultado: Point of View (POV) — "Como poderíamos [fazer X] para [persona] que [necessidade/insight]?"

3

Ideação (Ideate)

Gerar o maior número possível de ideias sem julgamento. Técnicas: brainstorming, SCAMPER, mapa mental, crazy 8s. Quantidade antes de qualidade.

4

Prototipação (Prototype)

Criar representações rápidas e baratas das ideias para aprendizado. Não precisa ser perfeito — o objetivo é aprender. Papel, wireframe, mockup, protótipo interativo.

5

Teste (Test)

Testar protótipos com usuários reais. Observar, não explicar. Coletar feedback para refinar o protótipo ou redefinir o problema. O processo é iterativo.

💡 Design Thinking não é linear
O processo pode (e deve) retroceder. Após testar, pode-se voltar à empatia ou redefinir o problema. A Cesgranrio pode cobrar essa característica iterativa e não-linear do Design Thinking.

Interoperabilidade de Interfaces Web

Interoperabilidade = capacidade da interface funcionar corretamente em diferentes navegadores (Chrome, Firefox, Safari, Edge) e dispositivos. Exige testes cross-browser, uso de padrões W3C, CSS resets e polyfills para funcionalidades não suportadas.

🚀
MVP & Prototipação

⭐ MVP — Minimum Viable Product
Versão de um produto com o mínimo de funcionalidades necessário para ser lançado, coletar feedback validado de usuários reais e aprender com o menor esforço possível. Conceito central do Lean Startup (Eric Ries).

MVP vs. Protótipo

AspectoProtótipoMVP
ObjetivoTestar design e usabilidadeValidar hipótese de negócio com usuários reais
FuncionalidadeSimulada / não funcionalReal e funcional (mínima)
UsuáriosTestado internamente ou em laboratórioLançado para usuários reais no mercado
CustoBaixo (papel, wireframe, Figma)Maior (produto real, mesmo que simples)
ResultadoFeedback de usabilidadeDados de comportamento real do usuário

Fidelidade de Protótipos

✏️
Baixa Fidelidade
Papel, sketches, wireframes simples. Rápido e barato. Foco na estrutura e fluxo, não no visual.
🖥️
Média Fidelidade
Wireframes digitais (Balsamiq, Axure). Estrutura definida, sem cores finais. Foco em interação.
🎨
Alta Fidelidade
Mockup interativo (Figma, Adobe XD). Visual final. Próximo do produto real. Mais caro e demorado.

Lean Startup — Ciclo Build-Measure-Learn

1

Build (Construir)

Transformar hipóteses em MVP — o menor produto que permite testar a hipótese.

2

Measure (Medir)

Coletar dados sobre como os usuários reais interagem com o MVP — métricas de comportamento.

3

Learn (Aprender)

Analisar dados para validar ou invalidar hipóteses. Decidir: Perseverar (continuar) ou Pivotar (mudar direção).

Storytelling com Dados & Dashboards

Storytelling com Dados

Storytelling com dados é a prática de combinar dados + visualizações + narrativa para comunicar insights de forma clara e persuasiva, guiando o espectador do dado bruto à decisão.

📊
Dados
A fundação — fatos, métricas, análises. Precisão e fonte confiável são essenciais.
📈
Visualizações
Gráficos, tabelas, mapas — tornam padrões visíveis e facilmente compreensíveis.
📖
Narrativa
Contexto, sequência lógica e conclusão — dão significado aos dados para o público-alvo.

🎯 Princípios de Dashboard Efetivo
  • Hierarquia visual: informações mais importantes em destaque (maior, mais escuro, mais alto)
  • Simplicidade: eliminar elementos desnecessários (chart junk)
  • Contexto: sempre mostrar comparativo (meta, período anterior, benchmark)
  • Consistência: mesma paleta, mesmos ícones, mesmas escalas em gráficos similares
  • Interatividade: filtros e drill-down para exploração
  • Mobile-first: dashboards devem funcionar em qualquer dispositivo

Organização e Apresentação de Dados em Relatórios

💡 Estrutura de Relatório Executivo
1. Sumário executivo — conclusão principal (leitores ocupados param aqui)
2. Contexto — por que esse relatório existe?
3. Dados e análise — evidências que sustentam a conclusão
4. Insights — o que os dados significam para o negócio?
5. Recomendações — ações sugeridas com base nos insights
