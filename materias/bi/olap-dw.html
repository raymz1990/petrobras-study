Operações OLAP

💡 O que é OLAP
OLAP (Online Analytical Processing) é uma tecnologia que permite análise multidimensional interativa e rápida de grandes volumes de dados. Os dados são organizados em cubos com dimensões (contexto) e medidas (métricas).

As 5 Operações Fundamentais

⬇️ Drill-Down — Do geral para o específico

O que faz: Desce no nível de granularidade — vai do resumo para o detalhe.

Exemplo Petrobras: Analiso produção por Ano → clico para ver por Trimestre → clico para ver por Mês → clico para ver por Plataforma.

Hierarquia de Tempo
Ano → Semestre → Trimestre → Mês → Semana → Dia → Hora

Direção: Da hierarquia mais alta (menos detalhada) para a mais baixa (mais detalhada).

⬆️ Roll-Up — Do específico para o geral

O que faz: Sobe no nível de granularidade — agrega dados do detalhe para o resumo. Operação inversa do Drill-Down.

Exemplo Petrobras: Vejo produção por Plataforma → agrego para ver por Bacia Sedimentar → agrego para ver por País → agrego para ver Total Global.

Operação matemática: Agrega (soma, média, contagem) os dados ao subir na hierarquia.

🔪 Slice — Fatia de uma dimensão

O que faz: Seleciona um único valor em uma dimensão — reduz o cubo de N dimensões para N-1 dimensões.

Exemplo: Cubo com dimensões Tempo × Produto × Região. Slice por Tempo = "Janeiro 2024" → resultado é um plano Produto × Região apenas para janeiro.

Analogia: Fatiar um cubo de queijo — você obtém uma fatia (plano 2D) do cubo 3D.

⚠️ Slice ≠ Dice
Slice: UMA dimensão, UM valor. Dice: MÚLTIPLAS dimensões, MÚLTIPLOS valores. A banca usa os dois em contextos similares — preste atenção ao número de dimensões filtradas.
🎲 Dice — Sub-cubo com múltiplos filtros

O que faz: Seleciona múltiplos valores em múltiplas dimensões — resulta em um sub-cubo (menor cubo dentro do cubo original).

Exemplo: Filtrar: Tempo ∈ {Jan, Fev, Mar} AND Região ∈ {Norte, Nordeste} AND Produto ∈ {Petróleo, Gás} → sub-cubo com 3×2×2 células.

Nome: Vem do dado (dice em inglês) — assim como um dado tem 6 faces, o Dice seleciona múltiplas faces/valores.

🔄 Pivot (Rotate) — Mudar perspectiva

O que faz: Rotaciona o cubo — troca a perspectiva de análise sem alterar os dados. Equivale a "transpor" as dimensões nas linhas e colunas.

Exemplo: Relatório com Produtos nas linhas e Meses nas colunas → após Pivot → Meses nas linhas e Produtos nas colunas.

Tabela dinâmica (Pivot Table) do Excel implementa exatamente essa operação.

Tipos de OLAP

💾
MOLAP
Multidimensional OLAP — dados pré-calculados em estrutura multidimensional proprietária (cubo). Alta performance de consulta. Limitado em volume. Ex: Microsoft Analysis Services (modo MOLAP).
🗄️
ROLAP
Relational OLAP — dados no banco relacional, cubo gerado dinamicamente via SQL. Escalável para grandes volumes. Mais lento que MOLAP. Ex: Mondrian, Google BigQuery.
🔀
HOLAP
Hybrid OLAP — combina MOLAP e ROLAP. Dados sumarizados em MOLAP (performance), dados detalhados em ROLAP (escala). Melhor dos dois mundos.
🌐
DOLAP
Desktop OLAP — cubo baixado para o cliente e analisado localmente. Sem conexão contínua ao servidor. Ex: análises offline no Excel.

Modelagem Dimensional — Revisão Aprofundada

Granularidade

⭐ Granularidade — Decisão Mais Importante
A granularidade define o que uma linha da tabela fato representa. Ex: cada linha representa UMA transação de venda (alta granularidade) vs cada linha representa o total diário de vendas por loja (baixa granularidade).

Kimball: "Quanto mais granular, melhor" — pois dados detalhados podem ser agregados, mas dados agregados não podem ser desagregados.

Tipos de Tabela Fato

TipoDescriçãoExemplo
Transaction (Transação)Uma linha por evento/transação — alta granularidadeCada venda de produto
Periodic SnapshotEstado de uma métrica em intervalos regularesSaldo de estoque ao final de cada dia
Accumulating SnapshotLinha atualizada conforme processo evolui — múltiplas datasPedido (data_pedido, data_pagamento, data_entrega)
Factless FactTabela fato sem medidas numéricas — registra ocorrênciasQuais estudantes participaram de quais eventos

Dimensões Especiais

📅
Dim_Tempo
Dimensão mais importante. Contém: data, dia da semana, mês, trimestre, ano, feriado, dia útil. Pré-populada com todos os dias do horizonte analítico.
❓
Dimensão Degenerada
Chave de negócio que fica na tabela fato sem dimensão própria. Ex: número do pedido (não há mais atributos para uma dim_pedido).
🔗
Dimensão Conformada
Dimensão compartilhada entre múltiplos data marts — garante visão consistente. Ex: dim_cliente igual no DM de Vendas e no DM de Suporte.
🌀
Dimensão Role-Playing
Mesma dimensão usada com diferentes papéis na fato. Ex: dim_tempo usada como data_pedido, data_entrega e data_cancelamento.

ROLAP vs MOLAP — Otimização

💡 Estratégia de Otimização por Tipo
MOLAP: otimização acontece no pré-processamento do cubo (cálculo de todas as agregações possíveis). Espaço de armazenamento pode ser 10x maior que os dados originais.
ROLAP: otimização via índices, particionamento, materialized views e armazenamento colunar no banco relacional. Mais flexível para dados muito grandes.
Modern DW (BigQuery, Snowflake): armazenamento colunar + auto-clustering + result cache — combina escalabilidade ROLAP com performance próxima do MOLAP.

Construção de Dashboards Interativos

KPIs no Topo
Métricas mais importantes em destaque visual — acima da dobra, com comparativo (meta, período anterior).
