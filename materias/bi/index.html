Hierarquia DIKW

A hierarquia DIKW descreve a transformação progressiva de dados brutos em valor para a organização.

D

Dado (Data)

Fatos brutos sem contexto. Sozinhos não têm significado. Ex: 42, 2024-01-15, SP, 150.000.

I

Informação (Information)

Dados com contexto e significado. Ex: "Em 15/01/2024, a unidade SP produziu 150.000 barris de petróleo (42 graus API)."

K

Conhecimento (Knowledge)

Informação processada, compreendida e aplicável. Ex: "A produção de janeiro foi 15% acima da média histórica, indicando melhoria nas técnicas de extração."

W

Sabedoria / Inteligência (Wisdom)

Conhecimento aplicado para tomar decisões melhores. Ex: "Com base no padrão identificado, expandir técnica para as unidades BA e RN no próximo trimestre."

Data Warehouse

⭐ Definição de Inmon (pai do DW)
Data Warehouse é uma coleção de dados orientada a assunto, integrada, não-volátil e variante no tempo, organizada para suporte à tomada de decisão.

As 4 Características do DW (Inmon)

🎯
Orientado a Assunto
Organizado por temas de negócio (vendas, produção, finanças) — não por aplicações ou departamentos como os sistemas OLTP.
🔗
Integrado
Dados de múltiplas fontes são padronizados e consolidados. Elimina inconsistências (ex: "M/F" vs "Masculino/Feminino" → padronizado).
🔒
Não-Volátil
Dados carregados não são alterados nem deletados. Apenas operações de leitura e carga. Histórico preservado.
📅
Variante no Tempo
Mantém dados históricos — cada registro tem uma dimensão temporal. Permite análise de tendências e comparativos históricos.

💡 Data Mart
Data Mart = subconjunto do DW focado em uma área específica do negócio (ex: Data Mart de Vendas, de RH, de Produção). Mais rápido de implementar. Pode ser dependente (criado a partir do DW) ou independente (criado diretamente das fontes).

OLAP — Online Analytical Processing

OLAP é uma tecnologia que permite análise multidimensional de dados de forma interativa e rápida. Os dados são organizados em cubos com dimensões e medidas.

💡 Cubo OLAP
Um cubo OLAP não é literalmente um cubo — pode ter N dimensões. Ex: cubo de vendas com dimensões Tempo × Produto × Região. A interseção de dimensões é uma célula com a medida (ex: valor de vendas).

Operações OLAP — As Mais Cobradas

OperaçãoO que fazExemplo prático
Drill-Down ⬇️ Desce no nível de granularidade — vai do geral para o específico Ver vendas por Ano → clicar → ver por Trimestre → clicar → ver por Mês
Roll-Up ⬆️ Sobe no nível — agrega dados do específico para o geral Ver vendas por Cidade → agregar → ver por Estado → agregar → ver por País
Slice 🔪 Seleciona um único valor de uma dimensão — reduz o cubo em uma "fatia" Filtrar apenas o mês de Janeiro (uma fatia do cubo temporal)
Dice 🎲 Seleciona múltiplos valores de múltiplas dimensões — sub-cubo Filtrar Janeiro e Fevereiro + Região Sul e Sudeste + Produto A e B
Pivot 🔄 Rotaciona o cubo — muda a perspectiva de análise Trocar linhas e colunas: de "Produto × Mês" para "Mês × Produto"
⚠️ Pegadinha — Slice vs Dice
Slice: UMA dimensão com UM valor fixo → resultado é um plano 2D.
Dice: MÚLTIPLAS dimensões com MÚLTIPLOS valores → resultado é um sub-cubo 3D+.
A banca dá o cenário e troca os nomes. Lembre: Dice = Dado (6 faces = múltiplos valores).

Tipos de OLAP

💾
MOLAP
Multidimensional OLAP — dados armazenados em estrutura multidimensional proprietária. Alta performance, mas limitado em volume.
🗄️
ROLAP
Relational OLAP — dados no banco relacional, cubo gerado dinamicamente. Escalável para grandes volumes.
🔀
HOLAP
Hybrid OLAP — combina MOLAP e ROLAP. Dados sumarizados em MOLAP, detalhados em ROLAP.

Business Intelligence

BI é o conjunto de técnicas, processos e tecnologias que transformam dados brutos em informação acionável para suporte à tomada de decisão empresarial.

Componentes do Ecossistema BI

1

Fontes de Dados (OLTP, APIs, Arquivos)

Sistemas transacionais, planilhas, APIs externas — onde os dados são gerados.

2

ETL / ELT (Integração)

Extrai, transforma e carrega os dados nas estruturas analíticas.

3

Data Warehouse / Data Mart

Repositório analítico centralizado e otimizado para consultas.

4

OLAP / Cubos

Camada analítica que permite exploração multidimensional dos dados.

5

Relatórios & Dashboards (Visualização)

Interface para o usuário final — Power BI, Tableau, Qlik, Looker.

BI como Suporte à Tomada de Decisão

💡 Diferença entre dado operacional e analítico
Dado operacional (OLTP): "Qual o estoque atual do produto X?" — resposta imediata, dado atual.
Dado analítico (DW/BI): "Como o estoque do produto X evoluiu nos últimos 3 anos e qual a tendência para o próximo trimestre?" — análise histórica e projeção.

Manipulação de Dados em Planilhas

Planilhas (Excel, Google Sheets) são ferramentas básicas de BI para análise exploratória. Funções essenciais cobradas:

Excel / Planilha 
=PROCV(valor; tabela; coluna; FALSO)     ← busca vertical
=SOMASE(intervalo; critério; soma)       ← soma condicional
=CONT.SES(int1; crit1; int2; crit2)     ← contagem múltiplos critérios
=ÍNDICE(matriz; linha; coluna)           ← retorna valor por posição
=CORRESP(valor; intervalo; tipo)         ← retorna posição do valor
Tabela Dinâmica (Pivot Table)            ← análise multidimensional
Segmentação de Dados (Slicer)            ← filtro visual interativo
