Operação de Segurança

Firewall, Proxy, IPS/IDS, DLP, CASB, SIEM, Antivírus, EDR, WAF, gestão de vulnerabilidades, monitoração e backup. O arsenal completo do analista de segurança.

⏱ ~60 min
🎯 Altíssima incidência

Destaques Cesgranrio — Operação de Segurança

  • IDS detecta e alerta (passivo); IPS detecta e bloqueia (ativo) — confusão clássica
  • SIEM correlaciona eventos de múltiplas fontes — não é só antivírus
  • DLP previne vazamento de dados — diferente de antivírus
  • WAF protege especificamente aplicações web (HTTP/HTTPS)
  • EDR é a evolução do antivírus — detecta comportamento, não só assinatura
  • CASB controla uso de serviços cloud (Shadow IT)

Segurança de Perímetro

Firewall

Controla o tráfego de rede com base em regras. Atua como primeira linha de defesa entre redes confiáveis e não-confiáveis.

GeraçãoO que inspecionaCaracterísticas
Packet FilterCabeçalho IP/TCP (IP, porta, protocolo)Stateless — não mantém estado da conexão. Simples e rápido.
StatefulEstado da conexão (SYN, ACK, FIN)Rastreia sessões — mais inteligente. Bloqueia pacotes fora de contexto.
Application Layer (NGFW)Conteúdo da aplicação (HTTP, DNS, SSL)Next-Gen Firewall — inspeção profunda de pacotes (DPI), reconhece aplicações.

Proxy

Intermediário entre cliente e internet. O cliente faz requisição ao proxy, que a encaminha em nome do cliente.

➡️
Proxy Forward
Representa o CLIENTE. Controla acesso à internet, filtra conteúdo, registra acessos, cache de conteúdo.
⬅️
Proxy Reverso
Representa o SERVIDOR. Balanceia carga, termina SSL, oculta servidores internos, cache de respostas.
🔒
Proxy Transparente
Intercepta tráfego sem configuração no cliente. Usuário não sabe que está passando pelo proxy.

WAF — Web Application Firewall

💡 WAF vs Firewall Tradicional
Firewall tradicional opera nas camadas 3-4 (IP, TCP/UDP) — filtra por IP e porta.
WAF opera na camada 7 (aplicação HTTP/HTTPS) — inspeciona o conteúdo das requisições web, detectando SQLi, XSS, CSRF, Path Traversal e outros ataques web específicos.
WAF é complementar ao firewall, não substituto.

VPN — Virtual Private Network

AspectoVPN Site-to-SiteVPN Client-to-Site
ConectaDuas redes corporativas (matriz ↔ filial)Dispositivo remoto ↔ rede corporativa
Uso típicoInterliga escritórios permanentementeFuncionário em home-office acessando intranet
ConfiguraçãoNos roteadores/firewalls das redesNo dispositivo do usuário (client VPN)
ProtocolosIPSec, GREOpenVPN, L2TP/IPSec, WireGuard

Detecção e Resposta

IDS vs IPS — A Distinção Mais Cobrada

AspectoIDS (Detection)IPS (Prevention)
AçãoDetecta e ALERTADetecta e BLOQUEIA
ComportamentoPassivo — não interfere no tráfegoAtivo — interrompe tráfego malicioso
Posição na redeOut-of-band (cópia espelhada do tráfego)Inline (fluxo de dados passa pelo IPS)
RiscoFalso negativo (não detecta ataque real)Falso positivo (bloqueia tráfego legítimo)
Impacto na latênciaNenhum (não está no caminho)Pequeno (tráfego passa pelo dispositivo)
⚠️ Pegadinha Clássica
"O IDS bloqueia automaticamente o tráfego suspeito" → FALSO (isso é o IPS).
"O IPS apenas gera alertas sem tomar ação" → FALSO (isso é o IDS).
IDS = Detection = Diz (alerta). IPS = Prevention = Para (bloqueia).

Tipos de Detecção

📋
Baseado em Assinatura
Compara padrões com banco de assinaturas conhecidas. Rápido e preciso para ameaças conhecidas. Ineficaz contra zero-day.
📊
Baseado em Anomalia
Aprende o comportamento normal e alerta desvios. Detecta zero-day mas gera mais falsos positivos.
🔬
Baseado em Política
Verifica conformidade com políticas definidas. Ex: alerta se protocolo não autorizado for detectado.

SIEM — Security Information and Event Management

⭐ O que o SIEM faz
SIEM coleta logs e eventos de segurança de múltiplas fontes (firewall, IDS, servidores, aplicações, endpoints), correlaciona esses eventos para identificar padrões de ataque e gera alertas centralizados.

Exemplo: 5 falhas de login em servidores diferentes em 2 minutos → SIEM correlaciona e alerta: possível ataque de força bruta distribuída.
Função SIEMDescrição
ColetaAgrega logs de firewalls, IDS/IPS, servidores, aplicações, endpoints via agentes ou syslog
NormalizaçãoConverte diferentes formatos de log em estrutura padrão para correlação
CorrelaçãoAplica regras para identificar sequências de eventos que indicam ataque ou incidente
AlertasGera alertas priorizados para a equipe de SOC (Security Operations Center)
RetençãoArmazena logs históricos para investigação forense e conformidade

DLP — Data Loss Prevention

DLP monitora e controla o movimento de dados sensíveis para prevenir vazamentos — intencionais ou acidentais.

🌐
DLP de Rede
Monitora tráfego de rede — bloqueia envio de CPFs, cartões de crédito por email ou upload não autorizado.
💻
DLP de Endpoint
Controla cópia para USB, impressão, screenshots de dados sensíveis no dispositivo.
☁️
DLP de Cloud
Monitora dados em serviços cloud (geralmente via CASB).

CASB — Cloud Access Security Broker

CASB é um intermediário de segurança entre usuários e serviços cloud. Oferece visibilidade sobre o uso de aplicações cloud (incluindo Shadow IT — apps não aprovadas pelo TI), aplica políticas de DLP, controle de acesso e conformidade.

Segurança de Endpoint

Antivírus vs EDR

AspectoAntivírus TradicionalEDR (Endpoint Detection & Response)
DetecçãoAssinatura — banco de vírus conhecidosComportamento + ML — detecta anomalias
Zero-Day❌ Ineficaz (assinatura não existe)✅ Detecta comportamento suspeito
RespostaQuarentena/remoção do arquivoIsolamento do endpoint, kill process, forense
VisibilidadeLimitada ao arquivo infectadoTelemetria completa: processos, rede, registro
InvestigaçãoNão — apenas alertaTimeline de eventos, threat hunting
💡 XDR — Extended Detection & Response
Evolução do EDR que integra telemetria de múltiplas camadas: endpoint + rede + cloud + email + identidade. Visão unificada para detecção e resposta a ameaças avançadas. Reduz silos entre ferramentas de segurança.

Gestão de Vulnerabilidades

1

Inventário de Ativos

Conhecer todos os ativos (servidores, endpoints, aplicações) antes de protegê-los.

2

Scan de Vulnerabilidades

Ferramentas como Nessus, Qualys, OpenVAS identificam vulnerabilidades conhecidas nos ativos.

3

Priorização (CVSS)

Common Vulnerability Scoring System (0-10) — prioriza patches pelo risco real (exploitabilidade + impacto).

4

Remediação

Aplicar patches, reconfigurar, mitigar ou aceitar o risco com justificativa documentada.

5

Verificação e Monitoramento

Confirmar que a remediação foi eficaz e monitorar continuamente para novas vulnerabilidades.

Backup e Continuidade

Estratégias de Backup

TipoO que copiaEspaçoRestauraçãoVelocidade backup
Completo (Full)Todos os dadosMaiorApenas o último fullMais lento
IncrementalMudanças desde o último backup (qualquer tipo)MenorÚltimo full + TODOS os incrementaisMais rápido
DiferencialMudanças desde o último backup COMPLETOMédioÚltimo full + último diferencialIntermediário
⭐ Regra 3-2-1
Boa prática de backup:
3 cópias dos dados
2 mídias/formatos diferentes
1 cópia offsite (fora do local principal)

Protege contra: falha de hardware, desastre local (incêndio, inundação) e ataque de ransomware.

RTO e RPO

⏱️
RTO — Recovery Time Objective
Tempo máximo aceitável para restaurar o serviço após uma falha. "O sistema deve voltar em até 4 horas." Define a URGÊNCIA da recuperação.
📅
RPO — Recovery Point Objective
Quantidade máxima de dados que pode ser perdida. "Não podemos perder mais de 1 hora de dados." Define a FREQUÊNCIA dos backups.
💡 Exemplo Petrobras
Sistema de controle de produção: RPO = 15 minutos (backup a cada 15min), RTO = 30 minutos (sistema deve voltar em 30min). Esses valores determinam a arquitetura: replica em tempo real, múltiplos data centers, hot standby.

Continuidade de Negócios — ISO 22301

BCM (Business Continuity Management) garante que a organização continue operando durante e após incidentes significativos. Documentos chave:

📋
BIA
Business Impact Analysis — identifica processos críticos e impacto de interrupções. Define RTO e RPO.
🗺️
BCP
Business Continuity Plan — plano para manter operações durante a crise (processos alternativos).
🔧
DRP
Disaster Recovery Plan — plano técnico para recuperar sistemas de TI após desastre.
